# Campaign writing package

This directory is the approved narrative source for the campaign rebuild.

- [CANON_AND_CONTINUITY.md](./CANON_AND_CONTINUITY.md) fixes the shared facts,
  terminology, causal routes, crew rules and four ending truths.
- [LINEWROUGHT_SCRIPT.md](./LINEWROUGHT_SCRIPT.md) contains the Linewrought
  opening, route/ID table, optional branch rules and missions L1-L4.
- [LINEWROUGHT_SCRIPT_L5_L8.md](./LINEWROUGHT_SCRIPT_L5_L8.md) contains
  Linewrought missions L5-L8 and both endings.
- [AURELIAN_SCRIPT.md](./AURELIAN_SCRIPT.md) contains the Aurelian opening,
  route/ID table, optional logistics branch and missions A1-A4.
- [AURELIAN_SCRIPT_A5_A8.md](./AURELIAN_SCRIPT_A5_A8.md) contains Aurelian
  missions A5-A8 and both endings.

## Coverage

| Campaign | Main operations | Optional operations | Endings |
|---|---:|---:|---:|
| The Hands That Kept It | 7 before the choice | 5 | 2 |
| A Clean Account | 7 before the choice | 2 | 2 |

Every operation has a story purpose, briefing, preferred eligible radio lines,
neutral fallback and aftermath. Main operations also state why the battle occurs
and why its result opens the next stage. Stable node and legacy mission IDs are
recorded beside final display names.

## Handoff order

1. C02 versions the two route graphs and preserves old saves.
2. C03-C05 provide the locations named in the route tables.
3. C06-C07 implement objectives and encounter data from the scripts.
4. C08 moves approved text into campaign stories, radio and wiki entries while
   enforcing speaker eligibility.

The prose in these files may be shortened for small UI surfaces, but factual
meaning, route causality and ending consequences must remain intact.
