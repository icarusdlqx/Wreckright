# Prepublication visual review

6 September 2026. The before images come from the production playthrough of
`8daa13d`; after images come from this upgrade round. These are inspected
examples of the same workflows, not pixel-aligned performance comparisons.
All browser profiles were isolated and headless. The user's desktop and saves
were not controlled or changed.

records. Its screenshot uses an explicitly staged completed battle result;
it is not evidence of a naturally completed campaign. The probe after image
also uses a controlled moving-target fixture; browser checks separately verify
rendered red pixels, motion, unchanged terrain fog and exact expiry.
